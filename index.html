為什麼我的結果後面還有 -A / -T？

例如 INTJ-A 或 ENFP-T，最後的 -A / -T 是 16Personalities 額外加入的 Identity 向度，用來描述對自己判斷的信心，以及面對壓力時的傾向。

  • A = Assertive：依該網站的定義，較傾向對自己的判斷有信心，面對壓力較不易動搖。
  • T = Turbulent：依該網站的定義，較傾向留意自我表現，對壓力與回饋比較敏感。

A / T 並不是傳統 MBTI 四個偏好字母中的第五個字母；末尾的 -T 也不同於第三個字母 T（Thinking）。本網站主要使用前四個字母介紹人格，A 與 T 沒有優劣之分。

16Personalities 和 MBTI 是同一個測驗嗎？

不是。16Personalities 使用自己的 NERIS 模型，以五個連續向度整理特質，借用了四字母形式；正式 MBTI 採用另一套理論與評量工具，兩者的結果不能直接視為相同。

本網站的稱號和「分析家、外交家、守衛者、探索者」角色分組，採用 16Personalities 的分類方式，並非傳統 MBTI 官方的四大人格群組。各頁的四字母解說則明確標示為 MBTI 偏好術語。

本教材不是官方測驗，也不蒐集或保存你的測驗結果。你可以從課堂使用的 16Personalities 測驗 ↗取得結果，再回來探索。

16 型選一張卡片，開始探索

分析家Analysts

紫人組N + T

從想法之間的關係出發，關注原理、推論與可能性。可以一起問：「這個想法站得住腳嗎？」

外交家Diplomats

綠人組N + F

從可能性與價值出發，關注事情對人有什麼意義。可以一起問：「我們希望帶來什麼改變？」

守衛者Sentinels

藍人組S + J

從具體資訊與安排出發，關注如何讓事情穩定運作。可以一起問：「下一步要怎麼落實？」

探索者Explorers

黃人組S + P

從眼前經驗與選項出發，關注實際嘗試後的新發現。可以一起問：「現在還能試試什麼？」

四個字母，裝不下完整的你。

人格測驗提供的是自我探索的角度，不是對一個人的完整定義。相同人格代號的人，仍可能因家庭、文化、經驗、年齡與情境而非常不同。

本網站不是心理診斷工具，也不應用來判定誰比較聰明、適合什麼科系、適合哪種工作，或誰和誰一定合得來。
